Random Quote Generator
======================

Description:
------------
This is a simple JavaScript project that displays a random quote each time the user clicks the "Generate Quote" button.

Features:
---------
- Uses plain JavaScript to select a random quote.
- Responsive layout using Bootstrap.
- Clean and minimalist design.

How to Use:
-----------
1. Open index.html in a browser.
2. Click "Generate Quote" to display a new quote.
3. Quotes are selected randomly from a preset list.

Technologies Used:
------------------
- HTML
- Bootstrap 5
- JavaScript

------
- index.html
