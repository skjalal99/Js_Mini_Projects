
Project Name: Counter App

Description:
This is a simple counter application that allows the user to increase, decrease, or reset a number using buttons. It uses basic HTML, CSS for layout and styling, and modern JavaScript for functionality.

Files:
- index.html - Structure of the webpage.
- style.css - Styling for the counter layout and buttons.
- script.js - Logic to handle button clicks and update the display.

How the JavaScript Works:
- Listens for DOM content to fully load before attaching event listeners.
- Updates a variable `count` on button clicks.
- Changes the displayed number and logs it to the browser console each time.

How to Run:
1. Open the folder in VS Code or any editor.
2. Open index.html in your browser or use Live Server.
3. Click the buttons to increase, decrease, or reset the counter.

Technologies Used:
- HTML
- CSS
- JavaScript (ES6)
