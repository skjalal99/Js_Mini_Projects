Digital Clock with Custom Date and Time Format
==============================================

Description:
------------
This is a simple digital clock web application using HTML, Bootstrap, and JavaScript. It displays the current time and date and allows the user to customize the display format.

Features:
---------
1. Live clock that updates every second.
2. Toggle option to switch between 12-hour and 24-hour time format.
3. Multiple date format options:
   - Long format (e.g., Monday, May 13, 2025)
   - Short format (e.g., 13/05/2025)
   - Minimal format (e.g., 13 May 2025)
   - Custom format where the user can choose to display:
     - Day
     - Month
     - Year

Usage:
------
1. Open `index.html` in a web browser.
2. The clock starts automatically in 12-hour format.
3. Use the toggle to switch to 24-hour time if needed.
4. Choose a date format from the dropdown menu.
5. If "Custom" is selected, you can select which parts of the date (day, month, year) to show.

Technologies Used:
------------------
- HTML
- CSS (via Bootstrap 5)
- JavaScript (Vanilla JS)
