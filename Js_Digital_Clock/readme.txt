Project Name: Digital Clock with Date (Using Bootstrap as Frontend)

Description:
This is a responsive digital clock application that displays the current time and date using HTML,
Bootstrap for layout/styling, and JavaScript for logic. The layout is centered and updates every second.

Files:
- index.html - Webpage structure using Bootstrap.
- style.css - Minor custom styles.
- script.js - Handles time/date updates.

JavaScript Functionality:
- Gets current time and formats it to HH:MM:SS.
- Gets the full current date in a readable format.
- Updates every second using setInterval.
- Time and date are shown on the page and logged in console.


Technologies Used:
- HTML5
- Bootstrap 5
- JavaScript (ES6)
